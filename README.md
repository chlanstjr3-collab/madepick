# MadePick · 메이드픽

요청하고 · 만들어주고 · 전시하고

MadePick is a bilingual community MVP for requesting apps, helping build ideas, and showcasing indie projects.

> This first version uses browser localStorage for submissions and votes. It is a prototype, not yet a real multi-user service.

## Start

```bash
npm install
npm run dev
```

## Deploy

The project includes a GitHub Pages workflow. In **Settings → Pages**, select **GitHub Actions** as the source to publish after pushing to `main`.

Production expansion: Supabase login/database, anti-spam moderation, actual user submissions and SEO-indexable database-backed pages.
